# Specs

Feature specs for this repository, one folder per change: `specs/<NNN>-<slug>/spec.md`.
Each spec is written from the feature-spec template (`templates/sdlc/feature-spec.md`) and
approved before implementation, and each scenario is built test-first (ADR-0004 — TDD + SDD,
`docs/architecture/decisions/ADR-0004-tdd-sdd-standard.md`). Both live in the owner's private
`architecture-docs` repository.
